# 方块沙盒 3D

独立的单人体素建造与勘探游戏，在 C Code Develop 内运行。SDL3 GPU 绘制 3D 场景，CCDUI 负责窗口、菜单和触控。

## 运行

在 CCD 的「从 Git 克隆」中打开 [项目仓库](https://github.com/XCBOSA/ccdmc)，然后用「运行项目」编译所有源文件。不要单独编译 `main.c`。建议使用带 SDL 音频、自定义 Metal 着色器和 CCDUI 触觉功能的 CCD iOS TestFlight 6.0.0（600000046）或更新版本。无音频后端时可静音运行。

- 左手摇杆移动，右手拖动转视角；轻点使用当前物品，长按连续挖掘。快捷栏最右侧是背包。
- 创造模式双点跳跃切换飞行，飞行时在右侧跳跃区拖动升降。生存世界会消耗补给，极限存档只有一次生命。
- 非和平生存中，水分和饥饿分别计算。奔走或游水会用水，晴天在沙漠、台地或稀树草原暴晒会更快。皮帽能减轻热负担，进阴影或下水能降温，但不会补回水分。水分低于 20% 会走慢，低于 10% 暂停自然回血，不会因缺水直接扣血。
- 行旅水囊：背包 2×2 合成格上排放皮革和线，下排左侧放玻璃瓶。对准静止水源轻点装满三口，移开准星再轻点喝一口；每口恢复 26%，瓶装水恢复 14%。满水分时不会误消耗。保存和重载会保留水分及水囊剩余量，旧存档首次载入从满水分开始。
- 营地集雨罐：背包 2×2 上排层压砌板、层纹玻璃，下排黏土球、复合密封垫。把罐放在露天，附近下雨时每约 6 秒存一口，最多三口；玻璃顶也会挡雨，下雪和干旱地带不蓄水。空手轻点查看存量，拿水囊轻点会按剩余空间取水。存量随世界保存；拆掉罐只回收空罐。
- 水位探头：背包 2×2 上排砖、层纹玻璃，下排铁锭、潮磨砂，一次做两个。拿探头轻点集雨罐侧面安装，向外的琥珀端可连灯或线路。默认至少存两口才输出；轻点探头切到空罐告警，只有罐内没水才输出。两种模式可同时装在不同侧，剩一口时两路都不亮，拆掉罐也不会误报。降雨和取水自动更新信号，不耗水，不轮询地图。旧式比较器不再合成或从创造背包新取，原来的线路保持可用。
- 滤苔床：背包 2×2 上排沙、砂砾，下排左侧黏土球，合成三块灰砂床基；泥纤胶和棕菇横摆，合成两个滤苔簇。把苔铺到灰砂顶面，床基只能有一侧接流动水，进水的对侧留空，苔上方也留空。浅流能让滤苔逐步蓄满两口，静止水源或多侧进水时不会工作。水囊轻点每次取一口，空手可查看存量。断流不补水，但仍能取出已蓄的水；蓄水随存档保留，拆下只回收床基和一个苔簇。
- 水力洗选槽：背包 2×2 上排烧结岩砖、层纹玻璃，下排铁锭、复合密封垫。槽顶放普通进料箱，一侧接流动水，正对入水面的另一侧放轻料箱，槽底放重料箱。可在进水面外留一格导水槽，把水源放在再外一格，铺底并用挡墙防止水绕到其他面。单侧水流每约 0.8 秒提供 1–4 格运力，木料、纤维和作物每件耗 1 格，岩料、矿料和玻璃每件耗 3 格；运力不足只搬轻料。两条路线轮流优先，某条路线箱满或缺箱时，其他路线仍可走。静水、断水或两侧进水会停机；工具、装备等不支持的货物留在进料箱。可空手轻点槽看状态，也可从侧面打开底下的重料箱。只在玩家附近已载入的区块运转，不补算离线时间。
- 创造背包的「生物蛋」分类有动物和怪物。选快捷格取用，再对准场景轻点释放。可合成和投放多色烟花。
- 苔壳行者是有四根支脚和亮甲缝的敌对生物；带护甲时不同部位的壳片会变色。导脉砂铺在完整方块的顶面，接上拉杆或营地探头后从暗铜色变成亮琥珀色。已有生物和线路无需迁移或重建。
- 余热回温台：背包 2×2 上排层压砌板、层纹玻璃，下排砖、铁锭。把台放在同高度的一座熔炉旁，等炉内没有能继续烧制的配方，空手轻点台取回已经点燃的余火；每 6 秒余火存一格，最多四格。台面有余热会亮起。拿磨损的铁工具或剪刀轻点，耗一格修复最多 12 点耐久，保留工具配件和名称；也可用两格余热将四片普通玻璃板熔回一块玻璃。装不下不会扣材料，台内蓄热随存档保留，拆下不会把余热带走。
- 暖陶芯：回收余火时，回温台旁若有一格空的石质地面，灰窑鼹可能来取暖。拿黏土球对准它轻点，用旁边一台回温台的 1 格蓄热换一枚暖陶芯。把暖陶芯带到另一台轻点，放热后留下空陶芯；之后持空芯可直接在回温台取热，不必再找灰窑鼹。满台或背包装不下时不会扣料。灰窑鼹也会在地热岩廊排压后出现，无群体攻击或掉金。
- 地图、地层、玩家装备、设施与生物都在本地存档。游戏运行期间可从存档菜单切换高级光影。
- 定期自动保存先在游戏线程生成一致的快照，再由后台刷盘并原子替换存档。菜单中的手动保存会等后台写入结束，再保存最新进度；失败不会拿不完整的文件覆盖原存档。
- 高级光影下，浅滩还能看到河床；水层越厚、视线穿过水体越斜，水面透出的海床细节越少，仍保留岸边倒影和波浪。
- 摄像机抬头或转向、没有水面可能入画时，跳过只供水面使用的倒影和水下视窗捕获。浪峰的位移也计入可见范围，不改变视距和画质。
- 草皮、树皮、木纹和砂砾由程序生成 32×32 纹理。岩石近景使用原生 64×64 细节：能看到砂岩颗粒、页岩层理和石灰岩孔隙；后退时逐渐切到同一纹理的低分辨率层。草地、土壤和石面仍按坐标选择变体。
- 存档菜单的「记录帧时」在返回游戏后采集 120 次游戏回调。终端分别显示静止、起停、区块内移动和跨区块时的回调间隔，并记录网格烘焙、上传、前方窄带覆盖和地形缓存淘汰。生物与载具的「可见」「跳过」统计按每次绘制检查累计，并单列实际上传顶点数，不代表存档中的个体数量。高级光影还记录反射与水上视窗跳过的水下网格。回调间隔不是屏幕刷新率，窄带统计不是全视野覆盖率。
- 新建的自然世界可以在深层找到层理页岩，在浅层沉积带找到孔隙石灰岩。页岩至少用石镐采集；两份页岩和一份石灰岩可在背包内冷加工为三块层压砌板。三种材料可分别建造。
- 柱岩海岸：新自然世界在部分近海区域生成高低交错的节理台阶。深色节理玄武岩可用石镐开采；浅色薄盖层下也可能有一层，用岩层探锤朝岩面轻点可分辨露头和浅埋回声。一份节理玄武岩和一份砂砾在合成格横向摆放，可做两块玄武路板。在路板上贴地步行快 18%；不加速游泳、攀爬或飞行。旧世界的原有岛屿保持不变。
- 潮砾蟹在水边岩面横走。拿一份砂砾对准它轻点可换潮磨砂，再等约 18 秒才可换下一份。一份玄武岩配潮磨砂能做三块路板，比直接用砂砾多一块；背包装不下时不扣料。创造背包也可取用潮砾蟹的生物蛋。旧红色牛型生物读档时恢复为普通牛，保留已保存的饲养状态、名字和栓绳。
- 裂隙引水廊：新建自然世界的部分地下洞穴接着一条灰岩步道和落水筛。长按挖掉高处浅灰色的黏土塞，水才会跌进低侧水槽。水落稳后，手持三份砂砾轻点筛子，洗出两份潮磨砂。重新堵上水路就停机。在自己的营地也能做筛：背包 2×2 上排烧结岩砖、层纹玻璃，下排砂砾、复合密封垫。筛顶留空，一侧贴连续三格的落水，静水和平流不算；背包装不下不会消耗砂砾。新自然世界的旧废矿道不再生成，既有世界及特意开启旧矿道的超平坦预设保留。
- 泥脊兽在浅水和湿黏土边活动。把黏土放在一格深的水底，或紧贴同高度的水且顶上留空；泥脊兽在上面翻泥约九秒，床面会变成浅金色纤纹。用锹轻点收一份泥纤胶，黏土留在原处，可接着翻泥。水退、离开泥床或受惊会打断；背包已满不扣耐久。背包 2×2 上排两根线、下排皮革和泥纤胶，可做两根软牵绳；泥纤胶也能给活塞做抓附层。攻击泥脊兽没有胶、不会分裂。旧热区方块生物和对应生物蛋读档后转为岩簧蜥。
- 新建世界的沙漠里有露天风蚀矿阶。沿较缓的一端进入，探锤能区分两侧的页岩、石灰岩和浅埋薄层。带石镐可以就地取样并加工砌板；无需触发机关或开宝箱。旧存档的地形不随此更新重排。
- 错层采样廊：新建自然世界的深洞会接上有高低岩台的采样廊。用探锤轻点低台的蓝色交界岩和高台的暖色交界岩，各取一枚样片，原岩留下且不会重复出样。背包 2×2 上排页岩样片、石灰岩样片，下排层纹玻璃、铁锭，合成地层测线尺。对竖直岩壁轻点，会分别提示左、中、右三条测线的露头、埋深或中断；不会跨过空洞和未加载区域假报。关闭结构生成的世界没有采样廊；旧存档保留原地形版本。
- 石浆模床：用一份孔隙石灰岩、一块木板和一颗黏土球在背包里合成。架在露天水岸，模床顶部留空、侧面接水；先拿一份石灰岩轻点调浆，再拿一份页岩压实。排掉侧水后空手轻点，取出三块层压砌板，模床可以再用。相比背包即时冷加工，每批少用一份页岩，但需要安排给水和排水。两种中间状态都会存档。
- 工况校准台：2×2 合成格上排放砌板、铁锭，下排放页岩、木板。生存中轻点台面，选中装备后按实际用料操作，无经验或随机要求。花一份页岩给石质或更坚固的镐装分层刃，加快开挖；或花一份石灰岩装取芯夹，让未被修改的原生岩层掉落双份岩材，多判定一次磨损。两种配件互斥；花一份层压砌板可恢复装备最多 16 点耐久，不更换配件。
- 野外调剂台：2×2 上排层纹玻璃、孔隙石灰岩，下排铁锭、层压砌板。水瓶放进快调、浓缩或雾化槽，分别耗 1、3、2 份原料，耗时 6、15、10 秒。同一台一次只处理一瓶，其他瓶子不会被一起转化。石灰岩隔热、南瓜恢复、柔光陶砖助潜、鸣壳片辨暗、棕菇缓力；隔热和恢复没有雾化档。加工中的瓶子随存档保存，先加其他瓶不打断。底漏斗只取成品，未加工的水瓶还留在台上。旧材料可取回，旧滤剂仍可使用。
- 营地设备：2×2 上排砌板、铁锭，下排铁锭、密封垫，做出岩甲巡护机；上排层纹玻璃、铁锭，下排柔光陶砖、密封垫，做出水冷脉冲机。手持设备轻点完整顶面部署。巡护机发现威胁才移动拦截，受损时用砌板修补；脉冲机固定在侧面接水的层压砌板上，减慢视线内的威胁但不造成伤害，断水停机，可用密封垫修补。空手轻点设备查看状态。摆放果实不会再激活旧搭法。
- 岩层探锤：在背包合成格任意摆放一份木板、一根木棍和一块圆石。手持探锤，对准岩面或土层轻点；墙面可敲出向内五格的线索，地面可向下探八格。沿线索用镐开挖，露头读数会提示所需工具。探锤不会消耗岩材，也听不穿空洞或流体。
- 深层含水带（新建世界）：用两份层压砌板、铁锭和木板合成勘测绞盘，架在实心地面并轻点下井。西侧潮沟需要下水后用探锤采样；东侧热裂隙先手持砌板轻点取样头封住气孔，再换探锤。两种岩芯和一份砌板能做六块导光嵌板。井底的缆索台随时可以返程，不必完成取样。
- 压力岩廊（新建世界）：完成两路取样后，从含水带北侧的圆环升降机继续下行。沿橙色地砖找到东西两路阀门，轻点打开；生存模式不要在未卸压的热气口前久站。两路打开后，手持圆石轻点北端烧结炉，每份圆石烧成两块烧结岩砖。阀门与建筑一起保存；升降机随时可以原路返回。
- 岩廊侧翼的裂岩甲兽在高压下会亮起橙色背脊，然后沿锁定的方向冲刺。侧移或绕到实心掩体后可以避开；冲刺后它会停下喘息。打开对应一侧排压阀，背脊会转青并停止攻击；探锤可以查看状态。也可在创造背包里找到它的刷怪蛋，在压力岩廊使用。
- 烧结炉附近栖息岩簧蜥。鳍片张开时，它会锁定方向，随后喷出一次贴地热汽；侧移或用实心墙遮挡即可。雪球能打断蓄汽并降温 12 秒，剩余降温时间会随世界保存。此时用探锤可无伤取下一片陶鳍，不能反复取同一只。将陶鳍在背包磨成两份多孔陶砂，放入调剂台的原料槽，快调槽放一瓶水，9 秒制成一瓶长效隔热剂。
- 鸣壳兽会出现在干燥、裸露的石灰岩上，在岩上停留约 12 秒后，背壳出现琥珀色纹路。此时用岩层探锤轻点可无伤采壳，留在栖地还会再长。壳片与一份层理页岩合成两块回声路标，可在暗处照明；也可与染料和火药合成双臂涡旋星。
- 夜间苗圃：在地面放一块回声路标，旁边同一高度种虞美人或蒲公英，路标上方留空。入夜后空手轻点路标，引来不会攻击的引光蛾。蒲公英照看两格内的苗床，约每 3 秒助长一株；虞美人范围扩展到三格，约每 5 秒助长一株。小麦、胡萝卜和马铃薯要种在湿润的耕地上，与路标同一高度且不隔墙；蛾优先照顾长得最慢的苗。苗圃只在玩家附近、区块已加载时工作，白天歇息；拆掉花或路标也会停止助长。旧存档中的磨砂晶屑可和玻璃加工成两片层纹玻璃。
- 居民接应：居民被野怪击倒后会就地等待，不会变成敌人，也不会在原住处刷出另一位居民。在他旁边同高度的一格放回声路标，脚下保持干燥，头顶留空；拿有水的水囊轻点，交给他一口补给。约七秒后可继续交易，原姓名和货单保留。拆掉路标、淹水、遮住头顶或走远都会暂停，不重复扣水。果麦干粮与接应无关：2×2 合成格上排苹果和小麦，下排左侧糖，合成两份干粮，可自己食用，也可喂坐骑。
- 工坊订单：轻点居民看工坊需要的两种材料、成品和剩余单数，直接从背包交付，不使用通用货币。最新一档完成两单就当场解锁下一档。第三档按工坊原址提供内陆、湿地或干热订单；例如装配师能分别提供巡护机、洗选槽或供气站。订单缺货后回到游戏待工坊补货，不用再做别的订单。材料不足或成品放不下不会扣料；每位居民的进度随存档保留。
- 潮帆鳐在浅水带活动，不会追逐玩家。用探锤对准水中的鳐轻点，可读取从鳐所在处通向换气水面的第一步。也可以用一份玻璃和一份孔隙石灰岩做两片层纹玻璃，再用一片层纹玻璃、页岩和铁锭合成潮路导盘。头部潜入水中时手持导盘轻点，按提示走几格后再测；它只读取附近已加载且连通的水道，不会隔墙指路，也不会消耗次数。
- 长潜补给：黏土球和皮革做两枚复合密封垫。密封垫、页岩、铁锭和层纹玻璃合成手摇供气站；密封垫和铁锭合成水下气嘴；页岩和铁锭做四段导气管。把供气站装在干处，顶部留空；沿共享的方块面铺管到气嘴。每条连通管路最多 24 段，只接一台供气站。在干处轻点供气站储压，每次加 2、最多 6；潜水后轻点气嘴，消耗 2 储压把氧气补满。断管、接错或氧气已满都不扣储压。储压和管路随世界保存。
- 储压信号箱：背包 2×2 上排层压砌板、层纹玻璃，下排铁锭、复合密封垫。拿信号箱轻点供气站的侧面安装；信号由朝外的琥珀色端口接出，可接灯、导线或其他接收器。空手轻点箱体，消耗 2 格储压，定向输出 1.5 秒；脉冲内再点不会扣储压。与潜水换气共用同一份补给。已有常通源仍可使用，不再新合成或从创造背包领取。
- 渗光陶艺：取一份页岩、孔隙石灰岩和黏土球合成渗光床。让水接触侧面、顶面留空，再拿黏土轻点：一面接水做两块柔光陶砖，至少两面接水做两块高亮陶砖。陶砖可搬去干处照明。新建自然世界在含水带的潮沟岸边有一处天然渗光床，无害的润脉甲也会在附近停栖。
- 新建世界的雨林里还有露天林冠集雨园。低侧水源已接到渗光床；挖掉高侧水槽口的黏土，让水跌入另一侧，再投一颗黏土球即可制成两块高亮陶砖。堵回槽口会退回单侧供水，可以用现场这段水路学习布置自己的水岸工坊。
- 旧点火框架不再启动远行；打开停在旧高热区域的存档时，退回地面安全落点。原有方块改动和背包保留，旧框内的光幕移除。已有自然世界的地形版本不变。
- 旧远征入口已停用。停在旧区的存档会在打开时把玩家送回安全的地面，保留背包和世界记录；旧奖励兑换为等量砂砾。正常保存后，下次从地面继续。
- 旧召唤装置不再开启战斗；相关建筑材料和设备在读档时转换为供气组件，原底座和其他建筑保留。旧光柱与范围增益不再生效。
- 旧暗藏生物的岩石和石砖恢复为普通建材，不再触发群攻。原来的生物记录和生物蛋转成润脉甲。
- 旧地形的地下房间保留入口和储物位置，中央通道打开，侧边可用探锤辨认并开采两种岩材。旧框架转换成普通石砖，不再出现传送面。联储箱可用两块木板、铁锭和石英在背包内合成；现有联储箱里的物品不变。
- 「超平坦」可选营地平原、浅湾航道、陶土工场等地层样板，也可输入材料配方，例如 `bedrock,4*loam,turf | meadow | settlements`。
- 支持实体键盘 WASD、数字键 1–9、E、Esc、空格与 F（飞行）。触控始终覆盖主要操作。

## 开发

`Contents/game/` 管理生物、角色、物品与交互；`Contents/world/` 管理地层、地形、流体与区块；
`Contents/render/` 和 `Contents/Shaders/` 管理 GPU 渲染与程序材质；`Contents/ui/` 管理界面；
`Contents/save/` 管理存档。源码与着色器随项目在设备上编译；材质与音效由代码生成。

执行 `sh scripts/test-core.sh` 跑世界和存档回归。网格改动再执行 `sh scripts/test-mesh.sh <CCD SDK include>`。
可用 `sh scripts/test-shaders.sh <Metal 验证工具的绝对路径>` 编译和检查着色器。
在 CCD 里用真实存档实跑、操作并查看截图后才视为用户界面已验证。运行、版本范围和发布边界见
[交付说明](docs/release.md)，玩法的设计记录见 [路线规划](ROADMAP.md)。
