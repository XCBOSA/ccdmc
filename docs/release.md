# 交付说明

这是面向触控的单人体素建造与勘探项目。玩法深度来自地层测线、压力岩廊、野外补给、营地水系、
加工和工坊订单，不以复刻外部游戏的关卡、数值表或版本作为交付标准。

使用支持 SDL3 GPU 和 Metal 源码着色器的 C Code Develop。将完整项目导入或从公开仓库克隆，
进入项目后点「运行项目」。不单独编译 `main.c`。可在同一设备创建创造、生存或极限世界；
联机和其他游戏的存档导入不在交付范围内。

## 本轮收尾

- 保留已有存档、方块和生物的稳定编号；新世界不会创建已退役的旧区域和关卡。
- 游戏界面的旧材料及地形称呼已清理。线路使用导脉砂和琥珀信号；保留导通、延时和营地探头行为。
- 苔壳行者使用四足支架、分层甲壳和单条亮缝，护甲改用对应甲片颜色。旧存档里的同类型生物读取为
  当前造型，不再显示原来的人形制服。旧关卡留存的同类小模型也用相同设计。
- 本轮不更改地形生成预算、视距、帧时设置或线上精选素材。自然世界的远景仍在后台逐步铺设，
  不把模拟器测试作为所有真机的帧率承诺。

## 当前源码与历史

运行材质和音效在项目源代码中生成，发布时不将测试存档、运行截图或 CCD 宿主二进制打入项目。
公开 `main` 以正常快进提交交付，旧提交和外部副本不因新提交而清除。无旧提交的快照制品
用于全新分发，不替代共享仓库历史，也不表示完成法律审查。
